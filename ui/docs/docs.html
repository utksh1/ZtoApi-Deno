Gateway Architecture

ZaiProxy API Documentation

ZaiProxy provides a zero-overhead, drop-in API translation gateway for Z.ai's cutting-edge GLM models. It natively exposes both OpenAI-compliant endpoints (/v1/) and Anthropic Claude-compliant endpoints (/anthropic/v1/).

Base URLs:
OpenAI Base URL: http://localhost:9090/v1
Anthropic Base URL: http://localhost:9090/anthropic

Authentication

All client requests must pass an authorization key using either standard HTTP Bearer token or Anthropic API key header:

Headers 
# Standard OpenAI SDK Header
Authorization: Bearer sk-your-key

# Anthropic Claude SDK Header
x-api-key: sk-your-key
anthropic-version: 2023-06-01

By default, any Bearer token matching the DEFAULT_KEY environment variable is accepted. If no upstream token is configured in .env, ZaiProxy automatically provisions and manages an anonymous guest session pool.

Quickstart Integration

Python (OpenAI SDK)

python 
from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:9090/v1",
    api_key="sk-your-key"
)

response = client.chat.completions.create(
    model="GLM-5.3-Flash",
    messages=[{"role": "user", "content": "Write an efficient binary search algorithm in TypeScript."}],
    stream=True
)

for chunk in response:
    content = chunk.choices[0].delta.content or ""
    print(content, end="", flush=True)

Python (Anthropic SDK)

python 
import anthropic

client = anthropic.Anthropic(
    base_url="http://localhost:9090/anthropic",
    api_key="sk-your-key"
)

with client.messages.stream(
    model="GLM-5.3-Flash",
    max_tokens=2048,
    messages=[{"role": "user", "content": "Explain reactive programming principles."}]
) as stream:
    for text in stream.text_stream:
        print(text, end="", flush=True)

OpenAI Chat Completions

POST /v1/chat/completions

Generates chat completions from messages. Supports streaming (Server-Sent Events) and non-streaming responses.

Request Parameters

Parameter Type Required Description
model string Yes Model ID, e.g. GLM-5.3-Flash, GLM-5.3, GLM-5.2.
messages array Yes Array of message objects with role and content.
stream boolean No Whether to stream chunks via SSE. Defaults to true.
temperature number No Sampling temperature between 0.0 and 1.0.
max_tokens integer No Maximum output tokens to generate.
tools array No List of tool functions forwarded to model.

OpenAI List Models

GET /v1/models

Returns the full list of available OpenAI-compatible models with their respective context limits.

Anthropic Messages API

POST /anthropic/v1/messages

Processes requests following the Anthropic Claude Messages protocol, automatically converting parameters and translating responses.

Anthropic List Models

GET /anthropic/v1/models

Returns active supported models (GLM-5.3-Flash, GLM-5.3, GLM-5.2) compatible with Anthropic SDK clients.

Anthropic Count Tokens

POST /anthropic/v1/messages/count_tokens

Estimates input tokens for a prompt before sending a full completion request.

Thinking & Reasoning Tags

GLM-5.3 models generate internal reasoning deliberation. Control how thinking content is returned via the X-Think-Tags-Mode header:

Mode Header Value Behavior
thinking X-Think-Tags-Mode: thinking Converts upstream <details> into <thinking>...</thinking> tags.
strip X-Think-Tags-Mode: strip Strips all reasoning blocks and returns only final text answer.
think X-Think-Tags-Mode: think Converts deliberation into standard <think>...</think> tags.
separate X-Think-Tags-Mode: separate Emits reasoning into the delta.reasoning_content field (DeepSeek format).
raw X-Think-Tags-Mode: raw Preserves upstream HTML tags untouched.

Multimodal Vision Support

The GLM-5.3-Flash model accepts vision payloads formatted in standard OpenAI image_url structures:

json 
{
  "model": "GLM-5.3-Flash",
  "messages": [
    {
      "role": "user",
      "content": [
        {"type": "text", "text": "Describe this architecture diagram in detail:"},
        {"type": "image_url", "image_url": {"url": "data:image/png;base64,..."}}
      ]
    }
  ]
}

Telemetry & Stats Endpoints

For custom monitoring and automated health checks:

GET /dashboard/stats

Returns JSON object with totalRequests, successfulRequests, failedRequests, and averageResponseTime.

GET /dashboard/requests

Returns array of the most recent requests with timestamps, paths, durations, and HTTP status codes.
